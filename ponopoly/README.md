# Po'Nopoly — Telegram Mini App

Онлайн-версия пародийной «Монополии» **Po'Nopoly by Darker Brothers** из фильма
«Не грози Южному Централу, попивая сок у себя в квартале» (1996).
Названия клеток — с той самой доски из кадра: Watts, Roscoe's Chicken & Waffles, Crenshaw,
Oakland, Echo Park, Alvarado, Florence, Pawn Shop, Nail Salon, Tax Evasion, Robbed, Drive-By,
колоды **No Chance** и **Community Service**, залог — **Disconnect Notice**. Клетки, которых в
кадре не видно, дополнены районами Лос-Анджелеса в том же духе (Compton, Inglewood, Slauson…
и в конце — Baldwin Hills с Beverly Hills).

Интерфейс на русском, названия на доске — как на реквизите.

## Доска из фильма

Сцена с Po'Nopoly есть только в **unrated-версии** фильма (после выхода Эштрея из тюрьмы
Прич, Лок Дог и Бешеные Ноги садятся играть); в прокатной R-версии её нет. Доска в игре
воспроизведена по кадрам этой сцены: **11 клеток на стороне, 48 всего**, пудрово-голубое
поле, цветные полосы на внутреннем крае клеток, горизонтальный логотип PO'NOPOLY в рамке,
подпись «by Darker Brothers» готическим шрифтом, персонаж с кубиками над логотипом,
зоны колод «NO CHANCE» и «COMMUNITY SERVICE» пунктиром.

Прочитано с кадров (в `js/data.js` такие клетки помечены `seen: true`):
сторона целиком — Westchester, No Chance, Oakland, Robbed (пистолет), Tax Evasion
(«PAY 10% OR …»), Echo Park, Community Service (ядро с цепью), Alvarado, Florence,
Pawn Shop, Normandie; угол с красным крестом (County Hospital); на соседней стороне —
Drive-By (пистолет), Roscoe's, Watts с фиолетовыми полосами; клетка Car Jacking;
карточки Disconnect Notice, купчие «RENT $12» с цветными полосами, жёлтые купюры $100,
золотые фишки (лоурайдер, пейджер, гильза), красные кубики.

Остальные 20 с лишним клеток в кадр не попали и **реконструированы** в том же духе
(Crenshaw, Slauson, Inglewood, Compton, Figueroa, Hoover, Lynwood, Koreatown, Hollywood,
Silver Lake, Venice Beach, Santa Monica, Malibu, Long Beach, Culver City, Westwood,
Brentwood, Baldwin Hills, Beverly Hills, Nail Salon, Liquor Store, Swap Meet, Barbershop,
Check Cashing). Цены и аренда — по шкале классической «Монополии»; мелкий текст под
названиями на кадрах не читается. Если пришлёте стоп-кадры других сторон доски, клетки
можно заменить на точные.

## Что умеет

- **Локальная игра**: 2–6 игроков на одном телефоне (передавая по кругу) и/или боты,
  названные в честь героев фильма (Ashtray, Loc Dog, Preach, Crazy Legs…). Партия сохраняется
  (в Telegram — в CloudStorage, в браузере — в localStorage), её можно продолжить позже.
- **Онлайн-комнаты**: хост создаёт комнату, друзья входят по 4-буквенному коду или по ссылке
  `t.me/<bot>/<app>?startapp=КОД`. Правила считает сервер, боты можно добавлять в комнату,
  отвалившийся игрок переподключается, а если пропал надолго — за него доигрывает бот.
- Полные правила: покупка, аукцион, аренда (монополия ×2, «точки», «салоны»), хаты и особняки
  с равномерной застройкой, залог/выкуп, сделки (деньги, клетки, карты выписки), County Hospital
  (дубль / $50 / карта / третья попытка), Tax Evasion (10 % или $200), банкротство с передачей
  имущества кредитору, опциональный банк на Free Parking.
- Telegram: тема (светлая/тёмная), имя игрока из профиля, кнопка «Назад», вибрация,
  подтверждение закрытия, приглашения через «Поделиться».
- **Два варианта доски**: «Как в фильме» (названия с реквизита: Watts, No Chance,
  County Hospital…) и «Полностью по-русски» (Уоттс, «Без шансов», Окружная больница,
  логотип «Нищеполия», карточки и имена ботов по-русски). Переключатель в главном меню,
  в настройках новой игры, в лобби онлайн-комнаты (задаёт хост) и в меню во время
  локальной партии. Набор переводов лежит в `js/ru.js`, его генерирует
  `tools/apply-ru.mjs` из JSON (с проверкой: 40 клеток, 32 карточки, без латиницы).

## Структура

```
ponopoly/
  index.html, config.js      клиент (Telegram Mini App), настройки
  css/styles.css
  js/data.js                 доска, карточки, фишки, функции локализации
  js/ru.js                   полная русификация (генерируется tools/apply-ru.mjs)
  js/engine.js               движок правил (чистые функции, JSON-состояние)
  js/bot.js                  боты (покупки, аукционы, застройка, сделки, долги)
  js/ui.js, js/main.js       рендер и логика экранов
  js/telegram.js             обёртка Telegram WebApp SDK
  js/storage.js, js/online.js сохранения и WebSocket-клиент
  server/index.js            сервер комнат + раздача статики (Node 18+, пакет ws)
  server/Dockerfile
  tools/bundle.mjs           сборка одностраничной версии (dist/ponopoly.html)
  tests/                     unit-тесты движка/ботов/сервера и e2e на Playwright
```

## Запуск локально

```bash
cd ponopoly
npm install
npm start            # http://localhost:8080 — клиент + сервер комнат (ws://localhost:8080/ws)
npm test             # движок, боты (25 партий до победителя), сервер
npm run e2e          # Playwright: локальная игра, онлайн на двух вкладках, сборка одним файлом
node tools/bundle.mjs   # dist/ponopoly.html — вся игра одним файлом, открывается с диска
```

## Как опубликовать как Telegram Mini App

### 1. Клиент

Вариант А — **GitHub Pages** (только локальный режим + онлайн, если сервер стоит отдельно).
В репозитории уже есть workflow `.github/workflows/pages.yml`: Settings → Pages → Source:
*GitHub Actions*. После пуша клиент появится по адресу вида
`https://<логин>.github.io/<репозиторий>/`.

Вариант Б — **сервер раздаёт и клиент, и комнаты** (один деплой, онлайн работает сразу).
Подойдёт Render, Railway, Fly.io, любой VPS с Node 18+ или Docker:

```bash
docker build -f server/Dockerfile -t ponopoly .
docker run -p 8080:8080 ponopoly
```

Нужен HTTPS (Telegram открывает Mini App только по https). Переменные окружения:
`PORT` (по умолчанию 8080), `DISCONNECT_GRACE_MS` (через сколько пропавшего игрока заменяет
бот, по умолчанию 120000).

### 2. config.js

```js
window.PONOPOLY_CONFIG = {
  serverUrl: 'wss://ваш-сервер/ws', // пусто — клиент ищет /ws на своём же хосте (вариант Б)
  botName: 'ponopoly_bot',          // для ссылок-приглашений
  appName: 'play',                  // короткое имя Mini App из BotFather
};
```

### 3. BotFather

1. `/newbot` — создать бота, запомнить username.
2. `/newapp` — выбрать бота, указать название, описание, картинку 640×360, **Web App URL**
   (адрес клиента из шага 1) и короткое имя (`appName`). Получится ссылка `t.me/<bot>/<app>`.
3. По желанию `/setmenubutton` — та же ссылка в кнопке меню бота.
4. Откройте ссылку в Telegram. Приглашения в комнату выглядят как
   `t.me/<bot>/<app>?startapp=КОД` — Mini App сам откроет экран входа в комнату.

## Отличия от настольных правил

- Нет лимита банка на количество хат/особняков.
- Заложенная клетка при сделке или банкротстве переходит без 10 % комиссии.
- Если денег «каждому по $10» у игрока не хватает, он отдаёт сколько есть (без долга).
- Аукцион стартует с любой ставки от $1, шаг свободный.

## Тесты

`npm test` гоняет: правила клеток и карточек, аукцион, залог, застройку, больницу, долги и
банкротство, сделки, детерминированность по seed, 25 партий ботов до победителя, а также
сервер (создание комнаты, вход по коду, старт, ходы, переподключение, замена пропавшего
игрока ботом). `npm run e2e` открывает игру в Chromium (телефон 390×844 и десктоп),
играет несколько ходов, проверяет сохранение после перезагрузки и онлайн-партию на двух вкладках.
